#### 🔧 Projects
##### flat-api - public
Arriving in London, we bought house plants in our first weekend. Everyone was worried that we'd kill our plants by either overwatering or neglecting them. I built and stood up this system in Azure, bought NFC stickers to post the watering updates and connected each of our phone numbers to receive updates via WhatsApp. It's an Azure function app written in python that also supports browser push notifications. I plan on making this available for multile households at some stage shortly.

##### Notice Board - <a href="https://polite-sea-029550e03.7.azurestaticapps.net/">public</a>

I built this project with the intention of actually using it myself to find and beat course records while I was living with my inlaws in Oslo, Norway.
AI blew up while I was on a career break - so I used this project to fast track my learning before getting back into the work force.

##### trolley-mates - private
Project I started about half way through our backpacking trip. We landed in Bolivia at a work away where I was able to help the owners of a local brewery set up a new beer factory server using brewblox. As well as this, I was able to use their computer to get connected and flex my brain a little! Basically this app has good bones, but the code doesn't deserve to see the light of day yet. At points in our trip I was writing code on my phone and pasting it into the repo, I was that desperate for some thinking!

**Data**: Grocery price database, where users would scan a receipt using their phone camera, we'd process it into readable text, parse it through to ML to classify and categorise each product.

**Search**: Search for an item and you'd find the best place to buy it for the lowest price in your area
